# Portfolio demo (5 minutes)

1. Install dependencies and run `python -m pytest -q`.
2. Show `prometheus/` and explain the adapter → normalization → provenance flow.
3. Run the CLI with an audited snapshot and `--as-of` cutoff.
4. Open the resulting PDF and the JSON audit export.
5. Point out a sourced KPI, its period, and the explicit `INSUFFICIENT_DATA`
   fields.
6. Explain that reports require human approval and are not investment advice.

The strongest verified demonstration in this repository is CURY3: 16/18
operational KPIs were traceable for 2026-Q1. Do not present that as coverage of
all sectors or as a performance track record.
