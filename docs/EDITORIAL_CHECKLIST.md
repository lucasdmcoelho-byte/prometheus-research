# Editorial approval checklist

- [ ] Ticker, issuer, security and CVM code match.
- [ ] Analysis cut-off and every material publication date are visible.
- [ ] No source was available after the cut-off.
- [ ] Units and periods reconcile; annual, YTD and quarterly figures are not mixed.
- [ ] All numerical claims have source IDs.
- [ ] Fatos CVM, documentos oficiais e componentes de peers reconciliam com os hashes brutos retidos.
- [ ] Calculations expose formulas and estimates expose assumptions.
- [ ] Facts, interpretations, estimates, risks and limitations are visibly distinct.
- [ ] Peer set is economically comparable and uses compatible periods.
- [ ] Sector-specific KPIs and relevant benchmark are present or explicitly unavailable.
- [ ] Bull/base/bear cases reconcile to the valuation engine.
- [ ] Contradictory evidence and thesis breakers are not suppressed.
- [ ] Governance, related parties and capital allocation were reviewed.
- [ ] No personalized recommendation, promise, stop-loss or allocation instruction appears.
- [ ] PDF pages were rendered and checked for clipping, overflow and unreadable charts.
- [ ] Todo documento oficial incluído na análise foi retido; arquivos escaneados/sem texto receberam revisão visual.
- [ ] JSON opens successfully and PDF/JSON hashes are recorded in the order ledger.
- [ ] Named reviewer recorded approval and notes.
